# 📋 My To-Do List (할 일 관리 애플리케이션)

사용자가 일상 업무, 학업, 개인 목표를 놓치지 않고 체계적으로 기록하고 관리할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🚀 실행 방법

별도의 설치(Node.js, npm, Python 등)나 빌드 과정 없이, 웹 브라우저에서 바로 열어 사용할 수 있습니다.

1. 파일 탐색기에서 `index.html` 파일을 더블 클릭하거나,
2. 웹 브라우저(Chrome, Edge, Whale 등) 화면으로 `index.html` 파일을 드래그 앤 드롭하세요.

---

## ✨ 주요 기능

1. **상/하단 분리 목록 (사용자 맞춤 요구사항)**
   - **진행 중인 할 일**: 아직 끝나지 않은 목표 태스크를 상단에 모아서 집중 관리합니다.
   - **완료한 목록 (하단 보관함)**: 체크박스를 누르면 완료 애니메이션과 함께 하단 '완료한 목록'으로 이동하며 완료 일시가 기록됩니다.
   - **접기/펼치기(아코디언)**: 완료 목록을 접어두거나 펼쳐서 이전 완료 내역을 한눈에 찾아볼 수 있습니다.
   - **원클릭 복원**: 완료 목록에서 체크박스를 다시 누르면 상단의 '진행 중' 목록으로 즉시 되돌아갑니다.

2. **직관적인 빠른 등록 & 세부 관리**
   - 상단 입력창에서 텍스트 입력 후 `Enter` 키로 즉시 등록.
   - 중요도 3단계 (높음 🔥, 보통, 낮음 ☕) 선택.
   - 마감일자 지정 시 **D-Day (오늘 마감, D-n, D+n 지남 경고)** 실시간 계산 뱃지 표시.
   - 카테고리 태그 분류 (💼 업무, 🏠 개인, 📚 공부, 🔖 기타).

3. **실시간 달성률 프로그레스 바**
   - 상단 헤더에서 오늘의 완료 현황과 달성률(%)을 시각적 게이지 그래프로 확인.

4. **필터링 & 정렬 & 검색**
   - 상태 탭 (`전체`, `진행 중`, `완료됨`).
   - 실시간 키워드 검색 (제목, 카테고리, 메모).
   - 정렬 옵션 (최신 등록순, 마감일 빠른순, 중요도 높은순, 가나다순).

5. **상세 및 수정 모달**
   - 할 일 카드 우측의 수정(연필) 아이콘 클릭 시 제목, 중요도, 카테고리, 마감일, 세부 메모를 편리하게 편집.

6. **영구 데이터 보관 (LocalStorage)**
   - 브라우저를 닫거나 새로고침해도 할 일 데이터가 그대로 유지됩니다.

7. **3가지 감성 테마 (라이트 / 다크 / 세피아 웜 모드)**
   - 우측 상단 테마 아이콘 버튼으로 3가지 모드를 자유롭게 순환 전환:
     - ☀️ **라이트 모드**: 화사하고 선명한 기본 모드
     - 🌙 **다크 모드**: 어두운 환경에서 눈부심을 줄여주는 다크 모드
     - ☕ **세피아(아이케어 웜) 모드**: 종이 질감의 따뜻한 베이지/크림 톤으로 장시간 작업 시 블루라이트와 눈의 피로를 최소화하는 모드
